# SM EVERFLOW ADMIN v0.5.0

실사용 현장 운영 버전.

## 핵심 변경
- 배치 흐름: 매입중 → 매입완료 → 출고대기 → 국제배송중 → 한국도착 → 통관중 → 통관완료 → 국내배송중 → 입고완료
- 배치 카드에서 즉시 `이 배치에 상품 추가`
- 예상 상품수 / 현지 매입총액 / 통화 / 환율 관리
- 상품 행 1클릭 수정
- 상품별 최대 10장 사진 보관 + 대표사진 1장
- iPhone 앨범 다중선택과 별도 카메라 촬영
- 당근마켓 / 번개장터 / 필웨이 계정 기준정보 관리
- 플랫폼 게시물과 판매·정산 연동 유지

## 사진 정책
ERP 재고 목록에서는 대표사진 1장만 사용합니다. 추가 사진 최대 9장은 검수증빙과 판매 플랫폼용 자료로 보관합니다.
